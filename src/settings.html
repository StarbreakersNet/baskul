Réglages de Bascule

Chargement…

Bienvenue dans Bascule ! Pour relier vos deux machines :

  1. Choisissez le rôle de cette machine. La principale est celle qui a le clavier et la souris.
  2. Le secret doit être identique sur les deux machines : copiez celui-ci dans les réglages de l'autre machine, ou collez ici le sien.
  3. Sur la machine principale, indiquez l'adresse de l'autre dans « Se connecter à ». L'autre machine laisse ce champ vide.

Enregistrez : Bascule redémarre avec ces réglages.

Le fichier de configuration ne peut pas être lu.
